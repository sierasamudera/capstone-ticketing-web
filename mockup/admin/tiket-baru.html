Buat Tiket TK- (Manual)

Dipakai untuk membuat tiket Technician Request resmi dari permintaan bantuan teknisi lain. Prefix ID otomatis TK-.

Mockup: tiket tidak benar-benar disimpan. Implementasi nyata: POST /admin/tiket/baru → add_ticket(ticket_type=Technician Request) (ID TK- otomatis, beban dihitung mesin, tetapi bukan kasus unik).

Aturan Tiket TK-

Dihitung sebagai beban

Durasi TK- masuk ke beban kumulatif teknisi di semua skenario.

Bukan kasus unik

TK- memakai Related Ticket ID, jadi tidak menambah jumlah kasus unik.

Wajib dua field

Related Ticket ID + Requested By tidak boleh kosong — server tetap memvalidasi.

v1.0.0 · Mockup statis tanpa server. Indikator pemerataan & skenario S4 adalah usulan yang perlu validasi dosen.
